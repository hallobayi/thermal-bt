# 2026-09-29 — Refactor RawThermal JS

## Yang dikerjakan

Refactor penuh `rawthermal-js` (helper PWA → Raw Thermal Android), dari satu
berkas 150 baris menjadi modul-modul kecil + build + test.

### Struktur baru

- `src/config.js` — DEFAULTS + `withDefaults()` (satu-satunya tempat normalisasi opsi)
- `src/platform.js` — `isAndroid(win)`, murni, bisa dites tanpa browser
- `src/intent.js` — `buildViewIntent(url, packageName, base)`, murni
- `src/text.js` — `buildTextDocument()`, `escapeHtml()`, murni
- `src/dom.js` — satu-satunya lapisan yang menyentuh `window`/`document`

- `test/bundle.test.js` — 12 uji `dist/` di dalam window tiruan

### Perbaikan bug (temuan analisis)

1. `npm run build` memanggil `build.js` yang tidak ada → sekarang ada.
2. `print()` cek `typeof === "string"` setelah `if (!options)` (urutan keliru).
3. Opsi dari `print()` bocor ke request → `withDefaults()` hanya meloloskan
   kunci yang ada di `DEFAULTS`.
4. `printText()` punya dua cabang `window.open` identik → disatukan.
5. Object URL `printText` tidak pernah dilepas → memory leak; sekarang
   di-revoke lewat `revokeObjectUrl`.
6. Nama `buildViewIntent` dobel (internal + publik) → shadowing dihapus.
7. `printBase64(base64, options)` dua parameter tak terpakai → dihapus.
8. `openInNewTab` ada di DEFAULTS tapi tidak pernah dibaca → sekarang dipakai.
9. `packageName` kosong menghasilkan `intent://…package=;` → sekarang ditolak.
10. Kegagalan popup-blocker ditelan senyap → hasil melaporkan `ok: false`.

### Pelajaran build (mahal, jangan diulang)

`build.js` mengekstrak body factory dari tiap modul. Dua pendekatan tekstual
GAGAL dan keduanya melaporkan sukses tanpa peringatan:

- `lastIndexOf("});")` — `Object.keys(...).forEach(function (k) {…});` di dalam
  body juga berakhir `});` → modul terpotong di tengah, sisa baris bocor jadi
  kode liar di bundel.
- `indexOf("{", marker)` — `{` di dalam default parameter ikut terhitung.

Solusi yang dipakai: penanda eksplisit `/* @body-start */` dan `/* @body-end */`
di setiap modul sumber. **Jangan hapus penanda itu.**

Dua bug runtime yang juga menyamar sebagai "kode benar":

- Entry factory dipanggil dengan `config, platform, …` padahal modul hanya
  tersedia sebagai `window.RawThermal*` → `config is not defined`. Argumen
  sekarang dibaca dari `global.RawThermal*`.
- Modul IIFE tidak menugaskan hasilnya (`(function () {…})();` tanpa
  `global.X =`) → entry membaca `undefined`. Sekarang setiap modul wajib
  `global.RawThermalX = (function () {…})();`.

Selain itu, `vm.createContext(win)` TIDAK membagikan objek host kembali —
nilai yang script set di `window` harus dibaca lewat `vm.runInContext(...)`.
Tanpa itu semua tampak `undefined` dan seolah ada bug yang tidak ada.
